# 文心雕龍・文法修辭練功站

繁體中文文法與修辭線上練功站：對象國小到高中，例句涵蓋韻文（詩詞曲／新詩／童謠）
與非韻文（文言文／白話散文／應用文），全遊戲化——閃卡圖鑑、Leitner 間隔複習、
弱點特訓、古代穿越冒險、PvE 歷代文心大師對戰、PvP 即時對戰、文心四靈養成。

- 線上：<https://wenxin-diaolong.vercel.app>（鏡像：`.pages.dev` / `.netlify.app`）
- 純前端無框架、無建置步驟；資料是靜態 JSON，改 `data/*.json` 即更新內容。

## 三分區

| 分區 | 內容 |
|---|---|
| 修辭 | 24 修辭格（國小8＋國中10＋高中6），逐格韻文／非韻文例句雙覆蓋 |
| 文法 | 詞性、詞語結構、句型、語病、文言虛詞／句式、詞類活用、標點 |
| 格律 | 押韻、對仗、平仄、詩體判別、詞曲常識、對聯 |

## 古代穿越冒險

已完成章回皆採用《文豪笑傳》的互動章回節奏重新包裝：進入人物篇前先從三句名言「開卷
立誓」，每幕以人物反差、對話與歷史處境推進，玩家必須作出三選一回應才能翻頁，
並以「史實小註」區分公版原典、可靠記載與本站原創橋段。教學委託因此成為故事中的
解謎或衝突，不再是獨立插入的題目頁。

第一章「先秦・莊子〈蝶夢逍遙〉」已可完整遊玩：現代殘卷、蝶夢之門、北冥風口、
庖丁迷陣、濠梁水畔、莊周論藝與守卷閣歸來。國小、國中、高中共用世界，依學段
切換文字與正式題庫類別；提供智慧注音、較完整注音與關閉注音。章回完成後尋回
「觀物之頁」，七日後以三題「蝶夢回聲」驗收是否穩固。

完成莊子主線後解鎖第二章「戰國楚地・屈原〈香草求索〉」：楚澤香草、江潭清濁、
九歌風陣、忠直之門、屈原問志與守卷閣楚聲歸來。第二章同樣提供三學段文字、智慧
注音、四組五題委託、三項收藏獎勵，以及七日後的「楚聲回音」；各章進度分開保存，
可從章回選擇返回莊子篇複習。

完成屈原主線後解鎖第三章外篇「孔子〈夢入杏壇〉」：玩家枕著《論語》入夢，依序
經歷學而之門、知之鏡、仁者之路、君子庭與孔子問學。國小、國中、高中各有 15 題
《論語》專屬題庫；所有委託只抽 `lunyu` 題庫，不混入一般修辭、文法或格律題。原文
採公版《論語》，題幹編排、選項、解析與夢境故事均為本站自編。

完成孔子外篇後解鎖第四章「漢代・司馬遷〈太史書魂〉」：玩家在漢宮竹簡長河中接過
司馬談未竟之志，穿行本紀、表、書、世家、列傳五條史路，再到鴻門夜宴辨人物語言，
最後與司馬遷進行「太史問筆」。國小、國中、高中各有 15 題《史記》專屬題庫，依序
深化詞性與句型、文言虛詞與句式、詞類活用與史傳敘事判讀；原文取自公版《史記》，
選項、解析與串場故事均為本站自編。

完成司馬遷篇後解鎖第五章「建安・曹操〈月下求賢〉」：從朝露、鹿鳴、烏鵲到山海，
把《短歌行》的生命焦慮、求賢用典與天下歸心拆成七幕。三學段首批各有 5 題專屬題庫，
章末由玩家與曹操進行「孟德問志」；後續將依序接續曹丕《典論・論文》、曹植《洛神賦》
與諸葛亮《出師表》。

每一組章回答題委託都有本站原創全幅情境插畫，題目不再脫離故事畫面；章末五題則
切換為文心對戰，第一章由玩家迎戰莊子、第二章迎戰屈原、外篇迎戰孔子、第四章迎戰司馬遷。答對只扣對手文氣，答錯
只扣玩家文氣，雙方不會在同一題同時受傷。

已完成的章回提供「重新遊歷本章」：會重新選擇開卷立誓並清空本輪三選一故事路線，
但保留原有收藏獎勵、七日回聲與後續章節解鎖，不必刪除整站進度。

冒險作答仍走既有 kernel、Leitner、文心珠與四靈進度，不建立第二套學習紀錄。

首次進站會設定冒險者姓名，並同步用於章回進度、莊子／屈原／孔子／司馬遷對戰、文心大師試煉與
文友過招。首頁「我的文心旅程」顯示章回百分比、目前位置、今日與累積答題、累積
正確率及文心珠數；姓名可從頁首隨時修改。

右下角接入自學星圖共用工具，展開後可使用家庭共學、學習紀錄（自學複利護照）、
返回自學星圖與匿名到訪統計。護照只同步白名單內的 `wxdl_meta` 與閱讀進度，不包含
班級憑證或其他網站資料。

學段：國小／國中／高中／實戰（實戰＝基測會考學測指考真題，答案照官方卡，附官方通過率）。
四個學段按鈕會切換成四套不同題庫，介面會即時標示目前題庫、對象、內容重點與分區題數；不是只改按鈕外觀。圖鑑另有國小／國中／高中累積篩選，高學段仍看得到前階段基礎。
修辭、文法、格律三個圖鑑分頁都有各自的國小／國中／高中分級大綱；切換學段時，已包含的前階段與目前所在階段會同步標示。
首頁六個功能入口皆使用本站原創古風水墨插畫，不以 emoji icon 代替內容配圖；文友過招另採左右文士對峙的回合制戰場，顯示雙方文氣、境界、連擊、回合與筆勢規則。

文心圖鑑已補成章節式講義：詞性涵蓋實詞六類、虛詞四類、助詞三分類、詞頭／詞中／詞尾與一詞多性；句型在國小先教並列、承接、轉折、因果、條件、選擇、假設、遞進、目的九類關聯複句，國中再拆解敘事、有無、表態、判斷四大句型；格律把五言、七言絕句的平起／仄起、首句入韻／不入韻八種基準格式直接拆成四行表，國中先練判讀，高中再學對黏、孤平、三平尾、三仄尾與拗救。深入內容可展開閱讀，不會把首頁壓成長篇課本。

長篇講義的每一節另有國小／國中／高中標記，依圖鑑學段累積顯示；閱讀時拆成單一步驟，完成後自動開啟下一步，百分比與已讀位置會保存在目前瀏覽器。

修辭採三階段大綱：國小先辨認 8 種基礎大類；國中加入 10 種進階修辭，並把核心概念向下細分（如譬喻四類、轉化三類、雙關三類）；高中再加入互文、示現、錯綜、鑲嵌、藏詞、飛白、移覺，進一步分析文言省略、多種修辭並用與表達效果。鑲嵌分為鑲字、嵌字、增字、配字；雙關是另一個修辭格，不列為鑲嵌子類。

內容撰寫遵守「查定義、自己造例句」原則：圖鑑示例均為本站自編，不搬用教材、題庫、網站或仍受著作權保護的作品。古典公版文本只在必要的文獻教學或正式考題情境中使用，並明確標示出處。

## 開發

```bash
python3 -m http.server 8000     # 本機預覽
npm test                        # schema + 資料完整性 + 純邏輯不變式
npm run smoke                   # Playwright 端到端煙霧測試
npm run merge                   # data/shards/*.json → 正式題庫（去重＋重編號＋驗證）
npm run extract:exam            # 重抽真題（來源：cap-guowen / gsat-guowen）
```

資料規格與誠信鐵律見 `docs/SPEC.md`。設計不變式（寵物等級 ≤ 真實精通量等）鎖在
`test/pet.test.mjs`，改公式前先讀它。

## 架構

- `js/schema.js`＋`js/quiz-loader.js`＋`js/bank.js`：資料層（分級分檔、載入即驗證）
- `js/meta/kernel.js`：養成機制唯一整合接縫（練習／對戰掛鉤 → events 陣列）
- `js/meta/pet.js`：文心四靈（等級＝該區精通題數÷20，答錯過的題加權 1.5）
- `js/adventure.js`＋`js/adventure-ui.js`：多章解鎖、各章進度、七日驗收與冒險 UI
- `js/story-content.js`＋`js/zhuyin.js`：三學段內容選版與注音安全渲染
- `data/adventure/zhuangzi.json`：莊子七幕、來源分層、任務與注音資料
- `data/adventure/quyuan.json`：屈原七幕、公版原典來源、分級任務與注音資料
- `data/adventure/confucius.json`：孔子外篇七幕、《論語》來源、夢境故事與分級任務
- `data/lunyu-*.json`：《論語》國小／國中／高中專屬題庫，各 15 題
- `data/adventure/simaqian.json`：司馬遷篇七幕、《史記》來源、史傳故事與分級任務
- `data/shiji-*.json`：《史記》國小／國中／高中專屬題庫，各 15 題
- `data/adventure/caocao.json`：曹操篇七幕、《短歌行》詩境、分級任務與對戰
- `data/duange-*.json`：《短歌行》國小／國中／高中首批專屬題庫，各 5 題
- `js/meta/masters.js`＋`data/masters.json`：PvE 大師名單（解鎖＝真實精通量門檻）
- `functions/api/`：Cloudflare Pages Functions＋D1（Redis 相容 shim），僅 PvP／排行榜用；
  鏡像平台透過 `js/meta/api.js` 打回權威平台 `wenxin-diaolong.pages.dev`
