# 文心雕龍古代穿越冒險：莊子首章設計規格

日期：2026-08-01
狀態：已完成對話設計確認，待使用者審閱書面規格

## 一、產品目標

將現有「文法修辭練功站」升級為古代穿越冒險。玩家是從現代誤入《文心卷》的少年行文者，穿梭歷代，遇見文人雅士、完成委託與論藝，修復遭「無字潮」侵蝕的文脈。

目標玩家同時包含國小、國中與高中學生。三個學段共用世界、角色與核心主線，但依閱讀能力調整文字密度、注音、提示、題目深度與支線內容。產品同時支援在家單人、教師帶班與同學互動；第一階段只實作可獨立驗證的單人垂直切片。

北極星指標為四項綜合結果：

1. 學習局完成率。
2. 七日回訪率。
3. 七日後短驗收的學習進步。
4. 健康使用：完成後願意收卷休息，而非被迫超長連玩。

## 二、已選方案與範圍

採「劇情冒險型」而非單純公開更多成就、商店與排行榜。第一階段製作：

> 現代教室 → 守卷閣 → 先秦莊子篇 → 五題委託 → 莊周論藝 → 修復第一張殘頁 → 七日後短驗收

### 第一階段包含

- 現代進入古代的可跳過序章。
- 守卷閣主基地的最小版本。
- 第一章「先秦・莊子〈蝶夢逍遙〉」。
- 國小、國中、高中三種適齡內容。
- 智慧注音、全文注音、關閉注音。
- 第一位同行四靈「雕龍」。
- 第一位文友「莊周」。
- 五題小局、局末結算、章末論藝與七日後短驗收。
- 既有進度的無損遷移與原功能回歸。

### 第一階段不包含

- 其他朝代與其他文人的完整章回。
- 帳號、跨裝置同步、班級房與教師控制台。
- 公開聊天、陌生人配對、賽季榜或社交獎勵。
- 新商店、付費、抽卡或 PvP 戰力膨脹。
- 一次接上全部 120 個遊戲化提案。

## 三、世界觀

「無字潮」正在侵蝕《文心卷》，使歷代文章中的辭采、章法與聲律逐漸消失。劉勰是身處卷外的守卷人；他不能改寫歷史，只能請玩家進入不同時代，重新理解並傳承失落文脈。

守卷閣是主基地。玩家每次返回，可查看文心卷修復程度、四靈、大師尺牘、收藏與下一個可達目標。未來世界依時代擴張為先秦、漢魏六朝、盛唐、兩宋、明清等篇章。

人物生平、作品原文、文學主張與特殊讀音必須有可靠來源並經人工覆核；穿越事件、角色對話、「無字潮」與「定形之網」明示為遊戲創作。既有「先秦第一奇喻大師」若保留，只能標為遊戲稱號，不能當成文學史定論。

## 四、第一章：先秦・莊子〈蝶夢逍遙〉

### 章回衝突

玩家被墨蝶帶入先秦篇。此地正受「定形之網」束縛：魚只能是魚、鳥只能是鳥，每句話只能有一種看法，寓言與想像逐漸失去力量。莊周先以問題試探玩家，再請玩家鬆開定形之網；通關後從試煉者成為第一位文友。

### 七幕流程

1. **現代・殘卷飛蝶**：選擇學段與注音模式，完成基本操作教學。
2. **蝶夢之門**：辨認譬喻、轉化與真實敘述，救出凝住的墨蝶。
3. **北冥風口**：透過鯤鵬意象理解誇飾、想像與觀看尺度；不把寓意壓成唯一標準答案。
4. **庖丁迷陣**：從語句線索找出結構與規律。
5. **濠梁水畔**：比較觀看立場，找出判斷所依據的文本證據。
6. **莊周論藝**：蝶影、巨魚與倒影形成五題章末挑戰；答錯生成殘墨線索，不立即結束。
7. **守卷閣歸來**：修復「觀物之頁」，雕龍同行，收到莊周第一封文友尺牘。

### 三學段差異

| 學段 | 表現方式 | 核心能力 |
|---|---|---|
| 國小 | 圖像、短句、智慧注音；每幕 3–5 分鐘 | 譬喻、轉化、誇飾、設問及短寓言線索 |
| 國中 | 增加角色立場、寓意與修辭辨析 | 譬喻與借代區辨、觀點判讀、寓意推論、文言詞語 |
| 高中 | 增加語境、多義、寓言論證與後世用典 | 用文本證據支持詮釋，理解多解仍須有判準 |

### 章回獎勵

- 文脈殘頁：「觀物之頁」。
- 同行四靈：「雕龍」。成長仍完全取自現有修辭精通。
- 文友：「莊周」，關係由「聞名」升至「問道」。
- 純外觀：「夢蝶書籤」，不提供 PvP 戰力。
- 七日後「蝶夢回聲」三題短驗收；通過後殘頁由「尋回」升為「穩固」。

## 五、核心遊玩循環

1. 抵達時代與場景，發現文脈異常。
2. 遇見文人，理解其處境與專長。
3. 接受 5–10 題有限委託。
4. 作答仍走現有學習核心；答錯顯示殘墨線索與提示階梯。
5. 完成任務，取得殘頁、信物或角色記憶。
6. 進入章末論藝，整合本章能力。
7. 返回守卷閣，看見永久變化與下一個目標。
8. 局末同等提供「收卷休息」及「繼續探索」；達標後優先建議休息。

第一章拆成可中斷小節，總長約 20–30 分鐘，不要求一次完成。新玩家應在 90 秒內進入第一題。

## 六、注音與適齡閱讀

### 三種模式

1. **智慧注音**：標示超出年級常用範圍的字、文言詞、人物地名、易誤讀字及任務關鍵詞；小三、小四預設。
2. **全文注音**：故事、對話、任務、題幹、選項、解析及按鈕均可顯示。
3. **關閉注音**：保留純國字版面。

使用網頁原生 `ruby/rt` 語意。注音資料以詞語或完整句子為單位，不做單字盲轉；多音字、人物地名、古文及特殊讀音須人工覆核。考查字音的題目必須隱藏相關注音，避免洩題。資料缺漏時降級為純國字，不猜讀音、不阻斷作答。

教師未來可指定班級預設，但學生仍可自行切換；不公開哪些學生使用全文注音。

## 七、系統架構

```text
章回內容資料
  ├─ 故事引擎：場景狀態、任務條件、章回進度
  ├─ 適齡選版：國小／國中／高中
  ├─ 注音渲染：智慧／全文／關閉、防洩題
  └─ 冒險介面：守卷閣、地圖、對話、結算
             ↓
        現有練習與 kernel
             ↓
Leitner／文心珠／四靈／大師／弱點／墨珠
```

### 邊界

- 冒險層只管理章回、場景、對話、任務與呈現。
- 題目判分、Leitner、文心珠、四靈精通、大師及墨珠仍由現有模組管理。
- 不建立第二份作答紀錄、第二套精通或另一份題庫。
- 故事引擎讀取現有 kernel 產生的完成、精通及修復事件，不自行增加學習數值。

### 章回內容資料

每章以資料描述：章回 ID、時代、場景、人物、史實或創作標記、來源、三學段文字、注音詞組、題庫篩選條件、通關門檻、獎勵及延後驗收。內容與程式邏輯分離，讓教師可直接覆核並支援後續增加朝代。

### 冒險轉接

「莊子委託五題」依 `zone/cat/level/difficulty` 從現有題庫選題，作答仍呼叫現有 `onPracticeAnswer`。完成結果再回傳故事引擎，推進場景與對話。一般練功、弱點複習與冒險共享唯一真實進度。

## 八、資料流

1. 讀取玩家學段、注音偏好與既有進度。
2. 載入莊子章回內容，選擇對應學段版本。
3. 故事引擎判斷目前場景與可接任務。
4. 任務從現有題庫挑出符合條件的題目。
5. 作答由 kernel 寫入唯一學習紀錄。
6. 故事引擎接收學習事件並推進章回。
7. 通關記錄「尋回」；七日後通過短驗收才記錄「穩固」。

第一階段維持免登入與本機進度，不新增外部服務。未來加入跨裝置或班級功能時，再另立規格處理身分、資料同步與安全。

## 九、失敗與安全降級

- 章回內容載入失敗：顯示可理解提示，原有練功仍可使用。
- 圖片載入失敗：回退現有 emoji 或純文字，不留下空白控制項。
- 注音缺漏：回退純國字。
- 任務篩不到足量題目：內容檢查阻止發布；正式環境不可用重複題灌水。
- 儲存版本不相容：先保留舊資料再遷移，不靜默覆寫既有精通、珠子或戰績。
- 延後驗收未到期：顯示可回來的日期，不用焦慮倒數、扣獎勵或失去資產。
- 故事狀態損壞：重建可推導的章回狀態，但保留 kernel 的真實學習進度。

## 十、測試與發布閘門

### 自動測試

- 場景解鎖、任務條件、三學段選版及七日驗收。
- 進度版本遷移與故事狀態重建。
- 注音模式、防洩題、缺漏降級與 HTML 安全輸出。
- 任務題數充足、所有路徑可達成、獎勵不可重複領取。
- 既有資料完整性、練功、圖鑑、四靈、PvE/PvP 測試全部維持通過。

### 內容稽核

- 人物年代、原典、文學主張、直接引文與來源。
- 史實、後世評語、遊戲稱號及虛構對話分層。
- 國小注音、多音字、文言讀音與人物地名人工覆核。
- 三學段內容不幼稚化、不超齡且不改變正確答案。

### UI 與無障礙

- 390px 寬無橫向捲動，三種注音模式無重疊。
- 鍵盤、螢幕閱讀器、減少動態、高對比及圖片失敗降級。
- 新玩家 90 秒內進入第一題；中斷後可續接小節。

### 使用者驗收

- 小三、小四在智慧注音下可獨立開始並完成第一小節。
- 三個學段完成後能說出至少一項修辭判準，而不只記得獎勵。
- 七日後短驗收表現優於首次表現。
- 超長連玩比例不因改版上升。

## 十一、實作分期

1. 內容 schema、來源與注音資料規格。
2. 故事引擎、進度版本與冒險轉接層。
3. 注音渲染及三學段內容選版。
4. 守卷閣、七幕莊子章回與局末結算。
5. 自動測試、內容覆核、無障礙與行動版驗收。
6. 小規模學生試玩；達發布閘門後才擴充下一位文人。

## 十二、完成邊界

第一階段只有在下列條件全部成立時才算完成：

- 莊子七幕可從頭到尾完成，並可中斷續接。
- 三學段及三種注音模式均可用。
- 原典、人物、注音與虛構標示完成覆核。
- 既有進度零遺失，舊功能回歸測試通過。
- 七日驗收邏輯可測，且不以改系統時間作為正式操作方式。
- 未通過內容、學習、無障礙或進度安全閘門時，不擴張其他朝代。
