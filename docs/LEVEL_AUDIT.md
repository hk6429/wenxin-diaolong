# 冒險題庫三級分級稽核

更新日期：2026-08-02

## 分級準則

依教育部國語文課綱的閱讀理解進程，本站把冒險題庫固定為三層能力，而不是只顯示
「國小／國中／高中」標籤：

| 學段 | 核心能力 | 題目分類 |
|---|---|---|
| 國小 | 找出人物、事件、景物與直接線索，完成單一步驟推論 | 明示訊息、事件順序、字詞理解、簡單推論、文體辨識 |
| 國中 | 統整句段關係，分析修辭作用、因果與觀點 | 句意詮釋、段落結構、修辭作用、推論統整、觀點辨析 |
| 高中 | 檢驗主張與證據，處理章法、多元詮釋及版本邊界 | 證據評鑑、章法分析、多元詮釋、思想辨析、版本文體 |

## 稽核結果與修正

- 原先後半段大量題目只有學段前綴與難度欄位不同，答案、選項高度重疊；現已重建。
- 莊子、屈原已退出通用修辭／文法／格律題庫，改用本人作品專屬題庫。
- 五十三章共 53 組人物題庫，每學段 615 題，冒險專屬題合計 1,845 題。
- 每題新增 `learningFocus`，答題畫面直接顯示學段與能力目標。
- 所有章回任務與七日回聲皆依學段分類抽題，不再靠不相符分類回退。
- 正確選項位置採輪替，不固定在第一個選項。
- 題目、選項與解析為本站自編；古典作品採公版文本並保留出處。
