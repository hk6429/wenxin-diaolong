# 遊戲化專家四：介面、節奏與自主權

本組十項以「學生一眼知道現在能做什麼，而且可以安心停下」為原則。

| 編號 | 優化 | 使用者可見效果 | 驗收條件 |
|---|---|---|---|
| U01 | 今日任務卡 | 顯示今天是否已開始及健康收卷提醒 | `mission` 隨今日題數變化 |
| U02 | 一鍵續玩 | 直接回到目前章回幕次 | `continueAdventure` 含章回與幕次 |
| U03 | 弱點捷徑 | 可直接進入需要複習的內容 | `weaknessShortcut.safe=true` |
| U04 | 短回合選擇 | 學生可選 5、10、15 題 | 三種題數與時間預估皆顯示 |
| U05 | 推薦分區 | 以精熟比例推薦最需補強區 | `recommendedZone` 有理由 |
| U06 | 獎勵預告 | 開始前說明可得到什麼 | 明示無抽卡、無隨機箱 |
| U07 | 精熟羅盤 | 同時比較修辭、文法、格律 | 三區皆有總數與百分比 |
| U08 | 下一里程碑 | 顯示距 25／50／75／100% 尚差多少 | `nextMilestone` 不為負值 |
| U09 | 靜心模式 | 可關閉非必要動畫與慶祝 | 明示不影響進度獎勵 |
| U10 | 自主權宣告 | 說清楚換區、離開不受懲罰 | 顯示不扣分、不清進度 |
