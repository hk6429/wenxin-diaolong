# 文心雕龍・文法修辭練功站 — 資料層規格書（v1，唯一權威）

所有題目資料（自編 shard、真題抽取、concepts 圖鑑）一律遵守本檔。違反 schema 的資料會被 `test/data-integrity.test.mjs` 擋下。

## 三分區與 id 前綴

| zone | id 前綴 | 說明 |
|---|---|---|
| 修辭 | `rh-` | 修辭格辨識與運用 |
| 文法 | `gr-` | 詞性、詞語結構、句型、語病、文言虛詞 |
| 格律 | `yl-` | 韻文專屬：押韻、對仗、平仄、近體詩、詞曲常識 |

id 格式：`{zone前綴}{學段碼}-{4位數}`，學段碼 `e`=國小、`j`=國中、`s`=高中、`x`=實戰真題。
例：`rh-e-0001`、`gr-s-0042`、`yl-x-0003`。merge 腳本會統一重新編號，shard 內只需保證自己檔內不重複。

## 一筆題目的完整 schema

```json
{
  "id": "rh-e-0001",
  "level": "國小",
  "zone": "修辭",
  "cat": "譬喻",
  "subcat": "明喻",
  "qformat": "rh-identify",
  "genre": "非韻文",
  "textForm": "一般語句",
  "question": "「妹妹的臉頰紅得像蘋果一樣」這句話用了哪一種修辭法？",
  "options": ["譬喻", "轉化", "誇飾", "設問"],
  "answer": "譬喻",
  "explain": "句中用「像」把臉頰比作蘋果，本體、喻詞、喻體齊備，是譬喻中的明喻。轉化是把物當人或把人當物來寫；誇飾是誇大或縮小事實；設問是自問自答或問而不答，皆與本句不符。",
  "origin": "自編",
  "citation": "",
  "difficulty": "易"
}
```

### 欄位規則

- `level` ∈ {國小, 國中, 高中, 實戰}；同一檔案內 level 必須一致（分級靠分檔）。
- `zone` ∈ {修辭, 文法, 格律}，必須與 id 前綴一致（rh↔修辭、gr↔文法、yl↔格律）。
- `cat` 必須在該 zone 的控制詞表內（見下）；`subcat` 選填自由字串。
- `options`：自編題固定 4 個、互異、非空；真題（exam-mc）允許 4~5 個。
- `answer` 必須在 options 內；`exam-mc-multi` 的 answer 是 ≥2 元素的陣列。
- `explain` 自編題必填，要逐選項辨析（為什麼對、其他為什麼錯），是教學的核心價值。
- `origin` ∈ {自編, 真題}；真題必填 `year`（民國年）與 `citation`（如「108年會考第23題」）。
- `citation`：凡題幹引用真實作品（古典詩/詞/曲/文言文一律視為引用），必填「作者〈篇名〉」；
  白話名家作品引用也必填。自編白話例句留空字串。
- `genre` ∈ {韻文, 非韻文}；`textForm` 控制詞表：
  - 韻文 → {古典詩, 詞, 曲, 新詩, 童謠, 歌謠, 對聯}
  - 非韻文 → {文言文, 白話散文, 小說, 應用文, 一般語句}
  genre 與 textForm 必須相符。
- `difficulty` ∈ {易, 中, 難}。
- 真題另可帶 `pass`（通過率 0~1 小數）、`disc`（鑑別度 0~1 小數）、`exam`（會考/基測/學測/指考）。

## qformat 白名單

| zone | qformat | 題型說明 |
|---|---|---|
| 修辭 | `rh-identify` | 給句子，問用了哪種修辭（選項=4個修辭格名） |
| 修辭 | `rh-pick` | 給修辭格，選出使用該格的句子（選項=4個句子） |
| 修辭 | `rh-odd` | 四句中三句同格，選出不同者（選項=4個句子） |
| 文法 | `gr-pos` | 詞性判斷（某字詞在句中的詞性） |
| 文法 | `gr-structure` | 詞語結構判斷（並列/偏正/主謂/動賓/動補） |
| 文法 | `gr-pattern` | 句型判斷（判斷句/敘事句/表態句/有無句、單複句、倒裝、被動） |
| 文法 | `gr-fix` | 語病判斷與修改（選出有語病的句子或正確修改） |
| 文法 | `gr-particle` | 文言虛詞用法（之乎者也矣焉哉的意義與用法） |
| 格律 | `yl-rhyme` | 押韻判斷（哪個字押韻/哪句不押韻） |
| 格律 | `yl-couplet` | 對仗與對聯（詞性相對、平仄相對、上下聯判斷） |
| 格律 | `yl-tone` | 平仄基礎（高中為主） |
| 格律 | `yl-form` | 詩體判別（絕句/律詩/五言/七言/古體/近體/詞/曲） |
| 真題 | `exam-mc` / `exam-mc-multi` | 官方考古題（單選/複選） |

## cat 控制詞表（依學段累加）

### 修辭
- 國小（8 格）：譬喻、轉化、誇飾、排比、設問、類疊、摹寫、感嘆
- 國中（+10）：借代、映襯、雙關、層遞、頂真、回文、引用、倒反、婉曲、轉品
- 高中（+6）：互文、示現、錯綜、藏詞、飛白、移覺
- 爭議格處理：擬人／擬物歸「轉化」（subcat 標明）；譬喻 subcat 分明喻／隱喻／略喻／借喻。
  各家分類有出入者（如激問歸設問），在 explain 註明通說，不自創體系。

### 文法
- 國小：詞性基礎（名詞/動詞/形容詞/量詞/代名詞）、標點符號、句子成分基礎（誰做什麼）
- 國中：詞性九大類、詞語結構（並列/偏正/主謂/動賓/動補）、句型（單句四型：敘事/表態/判斷/有無；複句）、語病判斷、詞類活用初步
- 高中：文言虛詞（之/乎/者/也/而/以/於/焉/其/矣）、文言句式（倒裝/被動/省略/判斷）、詞類活用、語病進階

cat 值用：詞性、詞語結構、句型、語病、文言虛詞、文言句式、詞類活用、標點符號

### 格律
- 國小：押韻、童謠節奏、對聯基礎
- 國中：押韻、對仗、詩體判別（絕句/律詩、五言/七言）
- 高中：平仄、近體詩格律、詞牌曲牌常識、古體近體之辨

cat 值用：押韻、對仗、平仄、詩體判別、詞曲常識、對聯

## 誠信鐵律（違者整批退件）

1. **引用必真**：凡標了 citation 的詩文，必須是真實存在、可查證的作品原文，一字不改
   （版本異文擇通行本）。不確定原文正確性就不要引，改用自編白話例句。
2. **不得假掛名家**：自編的句子絕不可標成名家作品。
3. **湊不齊配額老實回報**：某格某學段寫不出足量高品質題目，寧可短交並回報缺口，
   不可灌水（換湯不換藥的重複題、似是而非的爛題）。
4. **臺灣用語**：繁體中文、臺灣教學慣用術語（如「詞性」不用「词类」、「連接詞」慣例依臺灣課本）。
   禁止簡體字與中國大陸用語。標點一律全形。
5. **誘答有據**：錯誤選項必須是同學段學過的其他類別（同區同級誘答），且 explain 要能說清楚
   為什麼不是它。四個句子型選項（rh-pick/rh-odd/gr-fix）字數落差 ≤16 字。
6. **答案不洩題**：題幹不得直接出現正解術語（問「哪種修辭」的題幹裡不能先寫出「譬喻」）。
7. **答案位置隨機**：正解平均分布於四個選項位置，單一 shard 內任一位置占比不得超過 40%。

## 檔案佈局與所有權

```
data/
  rhetoric-elementary.json   grammar-elementary.json   prosody-elementary.json
  rhetoric-junior.json       grammar-junior.json       prosody-junior.json
  rhetoric-senior.json       grammar-senior.json       prosody-senior.json
  exam-rhetoric.json         exam-grammar.json         exam-prosody.json   ← scripts/extract-exam.mjs 產生
  concepts.json              ← 圖鑑卡資料（另一個專責 agent 產生）
  shards/                    ← 派工暫存區，merge 後即為歷史紀錄
```

shard 派工規則：每個 subagent 只准寫 `data/shards/` 下屬於自己的檔案，
不得動 schema/SPEC/其他 shard。主線程統一 merge。

## concepts.json（圖鑑卡）schema

```json
{
  "zone": "修辭", "cat": "譬喻", "level": "國小",
  "definition": "用另一件相似的事物來比方說明……",
  "tips": "口訣或辨識要領",
  "sections": [
    {"title": "深入主題", "body": "完整說明", "points": ["辨析一", "辨析二"]},
    {"title": "格式表", "patterns": [{"name": "類型", "form": "結構公式"}]}
  ],
  "sources": [{"title": "資料來源", "url": "https://example.edu.tw/"}],
  "examples": [
    {"text": "問君能有幾多愁？恰似一江春水向東流。", "genre": "韻文", "textForm": "詞", "citation": "李煜〈虞美人〉", "note": "以春水喻愁之綿長"},
    {"text": "他的心像一座冰山。", "genre": "非韻文", "textForm": "一般語句", "citation": "", "note": "明喻：本體（心）、喻詞（像）、喻體（冰山）齊備"}
  ]
}
```

每個 cat×最低出現學段一筆；examples 至少 1 韻文 + 1 非韻文（格律區豁免），引文誠信鐵律同上。
`level` 是本站建議的「首次系統學習階段」，不是教育部指定的唯一年級；圖鑑選擇國中或高中時採累積顯示，基礎概念不會從高學段消失。需要完整講授的核心概念可加 `sections` 與 `sources`；`body`、`points`、`patterns` 皆為可選欄位。
